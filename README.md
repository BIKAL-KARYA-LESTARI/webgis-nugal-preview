# WebGIS Nugal - Draft 1

Paket publik pratinjau teknis. Seluruh titik pada `draft-data.csv` adalah simulasi dan tidak mewakili kasus, individu, perusahaan, atau lokasi nyata.

## Isi yang boleh dipublikasikan

- `index.html`
- `draft-data.csv`
- `.nojekyll`

Dokumen kerja, PRD, memori kolaborasi, pengujian, data awal, dan data Google Sheets tidak termasuk paket publik.

Situs diberi `noindex,nofollow`. Ini mengurangi pengindeksan, tetapi tidak membuat URL privat. Siapa pun yang menerima URL tetap dapat membukanya.
